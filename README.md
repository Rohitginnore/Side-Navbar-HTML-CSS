# Side-Navbar-HTML-CSS

# 🧭 Side Navigation Bar (HTML & CSS)

This is a **mini frontend project** that demonstrates a **side navigation bar layout**
built using **pure HTML and CSS**.

The project focuses on UI structure, positioning, and clean styling.

---

## ✨ Features

- 📌 Side Navigation Bar
- 🎨 Clean and simple UI
- 🧩 Structured HTML & CSS
- 📱 Basic responsive behavior
- 🚫 No JavaScript used

---

## 🛠️ Technologies Used

- HTML5
- CSS3
